## Airwave (SoundTouch app)

The [`airwave/`](airwave/) folder contains Airwave, a replacement for the discontinued Bose SoundTouch app (TuneIn radio, presets, Bluetooth/AUX, multi-room, alarms). See [`airwave/README.md`](airwave/README.md) for setup.
